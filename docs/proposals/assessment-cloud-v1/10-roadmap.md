# 10 · 分阶段实施与测试

每一阶段都要先有上一阶段的确认。阶段之间可以停。停在任一阶段，现有测评仍按今天的方式使用。

## 阶段 0 · 确认（当前）

产出：本目录。  
退出标准：README 的 7 项确认有书面答复。没有答复就不进入阶段 1。

## 阶段 1 · 一条链路打通（职业六芒星）

范围：

- CloudBase 函数：提交、读取、撤销。
- 飞书「测评结果索引」建表（管理员操作，不在测评 PR 里「顺手创建」）。
- `js/cloud-kit.js`、`r/index.html`、六芒星挂点。
- 其他测评不出现上传块。

测试：

1. 不勾选同意：交卷后无网络请求，历史与导出图与现在一致。用浏览器网络面板核对。
2. 勾选后断网：结果页完整，队列有一条，恢复网络后点再试得到同一 reportId。
3. 同一队列重试两次：飞书只有一行。
4. 手机微信打开链接：不登录，能看到 3+3 个词，与交卷页一致。作答者浏览器改为无痕，链接仍能开。
5. 本机撤销后再打开：失效页，无词。飞书状态为已撤销。ASVA 读接口（可用 curl 模拟）返回 410。
6. 改词序再次生成：新链接是新顺序，旧链接仍是旧顺序。
7. 函数日志抽查：无昵称、无 linkSecret。
8. 仓库 diff 抽查：无 `score` 逻辑变更，无密钥。

## 阶段 2 · 低敏感、结构简单的外链与站内卷

顺序建议：巨婴 → 爱的 5 种语言 → SEFS → ECR → 珍爱金字塔（先文字+雷达）→ 霍兰德 → 个人充电。

每套只加挂点与一个只读模板。测试每套至少：

- 不同意不上传。
- 同意后 H5 的维度个数、主结论与原结果页一致（对照表放在该套 PR 描述里，用固定答案手测，不改计分测试的期望值）。
- 5 种语言：旧 `?r=` 仍能开，且新链接不是分数编码。
- 个人充电：同一天本地覆盖后，旧链接不变。
- 霍兰德：开放题在未勾选 `open_text` 时不出现在 H5 与飞书预览。
- 站外仓发布后，合集站卡片仍进入原来的线上地址。

## 阶段 3 · 临床与长报告

SCL-90、PDQ-4、Beattie 六套、心力地图。前置：阶段 0 里临床同意段落已定稿。

附加测试：

- SCL-90 第 15 题高分：H5 含原来的危机句；飞书预览只有「请打开完整报告」一类提示，无选项原文。
- 未勾选资料页同意：H5 无真实姓名；本地结果页仍有姓名。
- PDQ 可疑卷：verdict 标题与正文都在，不是只剩阳性个数。
- Beattie：交卷后清草稿，H5 仍能按保存的逐题或按 snapshot 声明阅读；六套 assessmentId 不会写进同一条。
- 心力地图：自述只在勾选开放题后出现；7 天会话过期不影响已生成的链接。
- 构建：Beattie 改 `beattie-src` 后，线上 `beattie/assets` 哈希更新，旧缓存参数失效。

## 阶段 4 · ASVA 导入

Staging 上：

1. 粘贴阶段 1 的六芒星链接，预览与 H5 一致。
2. 未选客户不能确认。
3. 确认后该客户多一条 SourceRecord，客户事实字段无变化（对照导入前后的客户 JSON）。
4. 再粘贴同一链接：不新增第二条。
5. 撤销后的链接不能导入。
6. 残缺链接、普通网页 URL、图片：都不发读取请求。
7. 生产发布按 ASVA 已有纪律，不在生产表上试第一遍。

寻根之旅 partial 放在这一阶段的最后，单独用例：请求体与 SourceRecord 的 raw_text 都不含手机号样例字段名 `phone`。

## 回归（每个阶段都做）

不上传路径是回归主体：

- 合集站 13 张卡片都能打开。
- 站内五套（含 Beattie 入口）昵称门槛仍在：空昵称不能开始。
- 交卷后本机历史条数规则不变（30 条、六芒星改序替换、巨婴同答案去重）。
- 导出图片仍能保存。
- 关页再开，会话恢复规则不变。
- `node --test` 现有计分测试保持通过。当前 `package.json` 只挂了 ECR；SCL-90 与 PDQ 的测试文件在各自目录，阶段 3 若改动相邻文件，应手动跑 `node --test scl90/js/score.test.mjs pdq/js/score.test.mjs ecr/js/score.test.mjs`。阶段 1 不碰这些文件时，跑一次作为基线即可。

## 停机与回滚

云函数下线时，测评页捕获提交失败，只显示本机结果。报告链接会打不开，索引仍在飞书。回滚前端就是去掉 cloud-kit 的 script 引用，不需要数据迁移。已写入的报告保留到管理员按保留政策删除，不随 Git 回滚而消失。
